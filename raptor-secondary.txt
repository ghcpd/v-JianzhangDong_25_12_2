## ✅ What was fixed
- **Root cause:** CPython **3.14** lacks wheels for heavy scientific libs; `pip` tried to **build from source** (`pandas`, `numpy`, etc.), requiring MSVC (`vswhere.exe`). Backup deps also fail because `distutils` was removed in 3.12+.
- **Remediation:** 
  - requirements.txt now uses **environment markers** to relax pins for **Python ≥ 3.14**, enabling pre-release/nightly binaries.
  - `auto_test.py` auto-adds **Scientific Python nightly wheels** index, `--pre`, `--prefer-binary`, `--only-binary=:all:` when on **3.14+**.
  - **README** updated with 3.14 guidance and fallback to Docker / Python ≤3.13.
  - **report.json** reasons updated to note the 3.14 strategy.
